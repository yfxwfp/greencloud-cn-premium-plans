# 绿云cn premium：套餐价格、配置与库存全整理，买前先弄清CPU限制和不退款规则

绿云cn premium 指的是 GreenCloud（绿云）的 CN Premium Optimized 系列 VPS，目前有东京和新加坡两个机房，月付 $25 起，走电信 CN2 GIA、联通 CU Premium、移动 CMIN2/CMI 的对华优化线路。这套机器线路定位很明确，但官方套餐页上有两行小字直接影响你的钱包：全系不支持退款，而且 CPU 有共享限制。这两条加上长期缺货的补货节奏，构成了本文要讲清楚的全部决策要点。

## 绿云cn premium 是什么线路？

一句话：CN Premium Optimized 是绿云专门面向中国大陆方向优化的高端 KVM 产品线，电信回程走 CN2 GIA，联通走 CU Premium，移动在东京走 CMIN2、在新加坡走 CMI。

两个机房的具体差异只有线路命名：东京标注为 "Tokyo, JP Premium Line (CN2GIA/CU PREMIUM/CMIN2)"，新加坡为 "Singapore Premium Line (CN2GIA/CU PREMIUM/CMI)"。套餐配置两地完全相同，都是 AMD EPYC Milan 处理器、NVMe RAID-10 存储、Virtfusion 控制面板、每日备份，每个套餐带 1 个独立 IPv4 和一个 /64 IPv6 段，操作系统只提供 Linux。

新加坡机房位于 Global Switch Singapore，官方给出的测试 IP 是 45.135.43.11（IPv6 为 2a11:8080:8::11）。下单前先 ping 一下这个 IP、看看到你本地运营商的路由走法，是成本最低的验证方式——实际路由会随运营商调度、地区和时段变化，测试 IP 只能当参考，但至少能排掉明显绕路的 Worst case。

## CPU 限制：平均 30%，100% 突发每天累计不超过 10 分钟

这是全网评测文章最少讲透、但对使用影响最大的一条。有用户就意外关机问题向绿云提交工单，把 CPU 限制问了个底朝天，官方回复如下：

- **适用范围**：所有未标注 VDS 的 KVM 套餐，包括 $25+/月的 CN Premium。官方原话是 "For KVM VPS services, CPU cores are shared, except for our VDS plans."
- **限制标准**："Average CPU usage should not exceed 30%. Bursts up to 100% are allowed for a maximum of 10 minutes every 24 hours."（平均 CPU 占用不超过 30%，100% 突发每 24 小时最多 10 分钟。）
- **10 分钟是累计口径**：官方确认 24 小时内所有满载时间加总不能超过 10 分钟。哪怕你每小时只跑 30 秒的 100%，30 秒 × 24 = 12 分钟，也算超限。
- **超限后果**：官方没说得特别死，表述是如果负载影响到节点上的其他客户，服务可能被重启、关机乃至暂停。

也就是说，cn premium 的所有套餐跑的都是共享核心。想在这条线路上跑渲染、编译农场、高并发爬虫这类持续吃满 CPU 的业务，基本可以死了这条心——这不只是"可能被限速"的问题，是明文写进规则的约束。

怎么看待这个条款，社区里有两种声音。提问的楼主认为平均 30% 还能接受，但每天累计 10 分钟满载"太严格了"，而且这更像一个兜底条款：没影响到别人时超了未必被处理，但官方随时可以拿它当停机理由，你没处说理。也有用户评价直接总结为"高负载业务别买低价档"。一个社区流传的土办法是用 systemd/cgroup 把整机 CPU 上限锁在 95%，理论上永远碰不到 100% 突发条款——能治标，治不了"平均 30%"那条。

还有一点值得记下：官方明确回复，目前没有在 CN Premium 线路上推出 VDS（独享核）配置的计划。想独享核心跑满载，这条产品线里没有选项。

## 不退款 + 经常缺货：下单前要接受的两个现实

全系不退款。官方购物车页在页面顶部就写着 "No refunds/money back on those plans"，每个套餐的备注里再重复一遍。没有试用期，没有冷静期，钱付了机器就是你的，路由不满意也是你的。

所以下单前用测试 IP 验证路由这件事，从"建议"升级为"必做"。社区用户对此的总结很直接：东京线路质量看运气，有人分到软银直连有人绕路，下单前务必先测 Looking Glass；不支持退款的套餐，宁可多花十分钟测路由，也别赌。

第二个现实是缺货。最近一次检查官方页面时，东京和新加坡全部 10 个 SKU 都是 0 可用。这个系列的补货节奏大致是：2026 年 4 月东京 Mini 有过一波，6 月新加坡 Mini 补货，9 月下旬东京和新加坡接连补过一次。低配套餐放出来很快就被抢完，二手市场上甚至出现了溢价转让——有人把自己到期的东京 Plan 1 按剩余价值加 50 元溢价、再加 76 元过户费挂出去，折算下来比官价贵了不少，侧面说明想直接原价买到并不容易。

## 适合谁买，谁该绕开

按已核验的配置和限制，判断其实不难做。

适合的场景：建站、反代、中转节点这类对回程线路质量敏感、但 CPU 压力不大的用途。CN2 GIA 加 CU Premium 的线路组合在晚高峰的价值，是普通国际线路 VPS 给不了的，这也是它比同配置普通机器贵的原因。每日备份和 Virtfusion 面板在这个价位算加分项。

该绕开的情况有三类。第一，持续高 CPU 负载的业务，前面说过原因。第二，需要 Windows 系统的，官方只提供 Linux。第三，需要退款保障来试错的——如果这是你第一次买对华优化线路、不确定路由到你家运营商的质量，一个不能退款的套餐显然承担不起"试试看"的成本。

预算参考一下也行：第三方比价站上，其他商家 8 核 16GB 档的对华/亚洲优化套餐大多在 $158–166/月之间，绿云 Plan 3 的 $165 在同价位里属于正常水平，它的差异化就在 CN2 GIA 线路本身。👉 用月付开通绿云CN Premium Plan 1，先跑一个月再决定要不要续

## FAQ

**绿云cn premium 有年付吗？** 有承诺周期降价机制，但被第三方追踪到具体数字的只有 Plan 1：3 个月 $43.65/月、6 个月 $42.75/月、12 个月 $40.50/月。其他套餐是否有同样档位，下单页会显示，以官方页面为准。

**超了 CPU 限制一定会被停机吗？** 官方的措辞是"可能"。条款写的是负载影响到节点上其他客户时，服务"可能被重启、关机或暂停"，实际执行有弹性。但弹性也意味着风险不可控，介意的话就按平均 30% 的口径来规划业务。

**缺货了怎么办？** 只能蹲补货。这个系列 2026 年内已经有至少三波补货记录（4 月东京、6 月新加坡、9 月两地），补货后低配套餐几小时内被抢完是常态。

**东京和新加坡怎么选？** 配置和价格完全一样，差别只在移动回程：东京走 CMIN2，新加坡走 CMI。移动用户建议两个机房的测试 IP 都测一遍，选路由更直的那个；电信和联通两地都是 CN2 GIA / CU Premium，差距不大。
